# Компьютерная графика: лабораторные 1, 2, 3 и 4

Единый репозиторий: исходники, шейдеры, текстуры и библиотеки общие. Нужная лабораторная выбирается CMake-пресетом. `LAB_NUMBER` передаётся одновременно в C++ и GLSL, поэтому интерфейс и отрисовка соответствуют выбранной работе.

```text
Labs/
├── .git/                      история прежнего vulkan-starter-app
├── source/                    общий C++ код
├── shaders/                   общие GLSL с переключением LAB_NUMBER
├── assets/                    изображения
├── third_party/
│   ├── stb_image.h
│   └── cache/                 один кэш исходников GLFW, ImGui, VMA, vk-bootstrap
├── docs/                      защита ЛР3, условия и архив до объединения
├── tools/                     генератор карт, проверки, экспорт контекста
├── CMakeLists.txt
├── CMakePresets.json
└── build/
    ├── lab1/lab1.exe
    ├── lab2/lab2.exe
    ├── lab3/lab3.exe
    └── lab4/lab4.exe           на Linux: lab4
```

| Preset   | Содержимое                                                                                                                                                                                                       |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `lab1` | Процедурные цвета вершин, проекции, трансформации, несколько сфер, анимация. Освещение и текстуры не применяются.           |
| `lab2` | Камера, Блинн–Фонг, ambient/directional, точечные лампы и прожекторы, материалы и направленные тени. Текстуры не применяются.       |
| `lab3` | Всё необходимое для текстурирования: файловые PNG, материалы, specular/emissive, анимация UV через push constants, staging-загрузка в DEVICE_LOCAL. |

Окно и панель подписаны номером лабораторной. Текстурные настройки видны в ЛР3–4, настройки света — в ЛР2–4. Старые версии исходников сохранены в `docs/archive/before-merge-2026-11-05.zip`.

## Лабораторная 4

Полностью реализованы тени солнца и выбранного прожектора через dynamic rendering, comparative sampler, PCF и настройки покрытия/depth bias. Готовая Linux-сборка: `./build/lab4/lab4`.

- [Инструкция и устройство ЛР4](docs/LAB4_README.md)
- [Текст для защиты](docs/LAB4_DEFENSE.md)
- [Полный контекст с кодом для нового чата](LAB4_CONTEXT_FOR_NEW_CHAT.md)

С Ninja: `cmake --preset lab4` и `cmake --build --preset lab4 --parallel`. Для текущей Linux-сборки на Makefiles используйте инструкцию по ссылке выше.

## Сборка из папки Labs

Нужны CMake 3.24+, Ninja, компилятор C++20, Vulkan SDK с glslc и драйвер Vulkan.

```powershell
cmake --preset lab1
cmake --build --preset lab1 --parallel

cmake --preset lab2
cmake --build --preset lab2 --parallel

cmake --preset lab3
cmake --build --preset lab3 --parallel
```

## Запуск

```powershell
.\build\lab1\lab1.exe
.\build\lab2\lab2.exe
.\build\lab3\lab3.exe
```

Ресурсы копируются рядом с каждым exe, приложение находит их независимо от рабочего каталога. Перед пересборкой закрывайте запущенный вариант. Кэш CMake не переносится со старого пути: после изменения расположения проекта нужно заново сконфигурировать сборку.

По умолчанию все три варианта используют 100 записей вершин (9×9 сегментов). Чтобы увеличить детализацию конкретной лабораторной до 506 вершин, используйте ту же папку сборки:

```powershell
cmake --preset lab3 -DLAB_SPHERE_LATITUDE_SEGMENTS=21 -DLAB_SPHERE_LONGITUDE_SEGMENTS=22
cmake --build --preset lab3 --parallel
```

Чтобы вернуть 100 вершин, задайте оба значения равными 9. Отдельные четвёртая и пятая папки сборок не нужны.

`third_party/cache` содержит только скачанные исходники зависимостей и исключён из Git. При его отсутствии CMake скачивает библиотеки туда. У каждой лабораторной свои объектные файлы в её build-папке: они зависят от определений компилятора. Перед первым параллельным конфигурированием нескольких лабораторных дайте одной конфигурации завершить скачивание общего кэша.

## Документация и проверки

- `docs/LAB2_DEFENSE.md` — рассказ, демонстрация и ответы для защиты второй лабы.
- `docs/LAB3_DEFENSE.md` — рассказ, демонстрация и ответы для защиты третьей лабы.
- `docs/LAB3_README.md` — подробности текстурных материалов.
- `LAB3_CONTEXT_FOR_NEW_CHAT.md` — единый самостоятельный пакет для другого чата по ЛР2 и ЛР3 (старое имя файла сохранено).
- `tools/export_context.py` — обновляет снимок кода в этом пакете.
- `tools/check_render.py` — проверяет третью лабу семью сценариями Vulkan-рендера и сравнением пикселей.
- PDF с условиями всех трёх работ находятся в корне Labs. Старые пособия ЛР1 сохранены; имена старых сборок в них относятся к структуре до объединения.

```powershell
python tools/check_render.py
python tools/export_context.py
```

Данные ЛР3 не генерируются при запуске: PNG загружаются библиотекой stb_image с диска. В ЛР1–2 для общей схемы дескрипторов загружается только служебная чёрная карта; их шейдеры не используют её в цвете поверхности.
